# 🤖 智能聊天机器人 - 小智

一个精美的可视化网页聊天机器人，支持智能回复、快捷交互和流畅的动画效果。

## ✨ 功能特性

- 🎨 **现代化 UI 设计** — 渐变配色、圆角气泡、流畅动画
- 💬 **智能回复引擎** — 基于关键词匹配的中文对话系统
- 😄 **丰富功能** — 讲笑话、讲故事、数学计算、查看时间
- ⚡ **快捷回复** — 一键发送预设消息
- ⌨️ **打字动画** — 模拟机器人思考中的打字效果
- 📱 **响应式布局** — 适配不同屏幕尺寸

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可开始聊天！

```bash
# 或者用任意静态服务器
npx serve .
```
